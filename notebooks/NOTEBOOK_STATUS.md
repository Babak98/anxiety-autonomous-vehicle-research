# Research notebook archive

This notebook preserves the five original experimental code cells from `random forest anxiety estimator.ipynb`. Saved outputs, execution counts, and original notebook/cell metadata have been removed from this publication copy. The code has not been modified or executed during preparation.

The notebook depends on Google Colab, the original `time_series-hand2.csv` dataset, and NumPy, pandas, matplotlib, seaborn, scikit-learn, and joblib. Dependency versions have not been recovered. The dataset and model binaries are not part of this proposed upload.

Multiple experimental variants are retained; this is an archive of research code, not a verified end-to-end pipeline. Cell 0 contains standalone numeric list expressions such as `[2]`. Some variants include participant ID (`pid`) as an input and use a random row split. Their scores should not be interpreted as evidence of generalization to unseen participants. Some preprocessing calculates min/max over the dataset before the split. A participant/trial-aware evaluation and training-only preprocessing need a separate, approved change and a rerun with the original data.

No benchmark score is claimed. No changes have been made to the original Drive files.
